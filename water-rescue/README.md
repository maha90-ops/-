# 🌍💧 مركز إنقاذ كوكب الماء — Water Rescue Mission
**مهمة اكتشاف دورة المياه في الطبيعة** · بيئة تعلّم رقمية غامرة لطلاب المرحلة الأساسية (عربية، RTL، تعمل دون إنترنت، قابلة للتثبيت PWA).

## التشغيل
التطبيق ملفات ثابتة بلا Backend ولا مكتبات خارجية ولا خطوة بناء.
```bash
cd water-rescue
python3 -m http.server 8080     # أو: npx serve .
# ثم افتح http://localhost:8080
```
> فتح `index.html` مباشرة (file://) يعمل للتجربة، لكن العمل دون إنترنت والتثبيت يحتاجان خادمًا (http/https).
للاستخدام الصفّي: ارفع المجلد إلى أي استضافة ثابتة تدعم HTTPS (GitHub Pages، Netlify…).

## العمل دون إنترنت (Offline First)
- عند أول زيارة يخزّن `service-worker.js` كل الملفات (٣٤ ملفًا: الشيفرة والخطوط والأيقونات).
- بعدها تعمل البيئة كاملة دون اتصال. الخطوط مضمّنة محليًا، والأصوات مولّدة برمجيًا.
- **عند تعديل أي ملف:** غيّر `VERSION` في `service-worker.js` ليحصل الطلاب على النسخة الجديدة.

## التثبيت كتطبيق (PWA)
- **Android / Chrome / Edge:** قائمة المتصفح ← «تثبيت التطبيق»، أو ⚙️ الإعدادات ← «📲 ثبّت التطبيق».
- **iPhone / iPad (Safari):** زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الكمبيوتر:** أيقونة التثبيت في شريط العنوان.

## بنية المشروع
```
index.html            الهيكل + ترتيب تحميل السكربتات
style.css             نظام التصميم (متغيرات، مكونات، مراحل، تباين مرتفع، حركة أقل، طباعة)
data.js               كل المحتوى التعليمي (نصوص، أسئلة، سيناريوهات) — عدّله دون لمس المنطق
app.js                الموجّه، شريط التقدم، الإعدادات، تسجيل Service Worker
manifest.json · service-worker.js
components/
  scenes.js           مكتبة رسوم SVG (شمس، سحب، جبال، مطر، بخار…)
  nemo.js             الروبوت المساعد «نيمو»
  ui.js               نوافذ، مكافآت، احتفال الشارات، أسئلة الاختيار، هيكل المرحلة
modules/
  utils.js · store.js (التقدم في localStorage) · audio.js (Web Audio + قراءة صوتية)
  intro.js · map.js · stage-*.js (٨ مراحل) · achievement.js (التقويم والشهادة)
assets/  fonts (Tajawal, Baloo Bhaijaan 2 — OFL) · icons · images · audio
```
المراحل سكربتات عادية (ليست ES modules) عمدًا، لتعمل حتى من file://. كل مرحلة تسجّل نفسها في `WR.views` وتعيد دالة تنظيف.

## نظام التحفيز
⭐ نجمة (١٠) لكل اكتشاف أو دليل · 💧 قطرة (٢٠) لكل نشاط مكتمل · 🌱 ورقة (١٥) لكل مشكلة بيئية · 🏅 شارة (٥٠) لكل مرحلة.
المكافآت لا تتكرر عند إعادة المرحلة. الخطأ لا يُعاقَب: «💙 محاولة جيدة!» مع تلميح، وتُعطى فرصة جديدة دائمًا.

## إمكانية الوصول (UDL)
لوحة مفاتيح كاملة (Tab / Enter / مسافة / الأسهم في مصنع السحب والترتيب) · بديل «اختر ثم ضع» لكل سحب وإفلات ·
✓ و ✗ ونص لقارئ الشاشة، لا الاعتماد على اللون · زر 🔊 لقراءة كلام نيمو (Speech Synthesis) · تباين مرتفع · حركة أقل
(يحترم إعداد النظام تلقائيًا) · خط أكبر · أهداف لمس لا تقل عن ٤٨px · لا وميض سريع · لا صوت قبل أول تفاعل.

## حفظ التقدم
`localStorage` (المفتاح `water-rescue-progress-v1`): الاسم، المرحلة الحالية، المراحل المفتوحة والمكتملة، النقاط، الشارات،
الإجابات وإحصاءات كل مفهوم، الأخطاء، الاكتشافات، والإعدادات. عند العودة تظهر «🔄 متابعة المهمة» و«🆕 بدء مهمة جديدة» (مع تأكيد قبل المسح).

## الاختبار
اختُبر آليًا بمتصفح Chromium (Playwright) على سطح المكتب (1366×860) وهاتف iPhone 13: رحلة كاملة من المقدمة إلى الشهادة،
إجابات خاطئة ثم صحيحة، التحقق من الاسم الفارغ، محاولة فتح منطقة مقفلة، إعادة التحميل والمتابعة، السحب بالفأرة، الأسهم،
تشغيل دون إنترنت بعد التخزين، ومعاينة الطباعة — دون أي أخطاء JavaScript.
