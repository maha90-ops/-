# ماذا لو كان الدرس يعرفني؟

**رحلة تكيفية لاكتشاف دورة المياه في الطبيعة** — نموذج أولي (Prototype) تفاعلي لبيئة تعلم رقمية تكيفية، لطلبة المرحلة الأساسية.

> نفس الهدف… رحلات تعلم مختلفة.

## التشغيل

لا يحتاج إلى خادم ولا إلى إنترنت: افتح `index.html` في المتصفح مباشرة (نقرًا مزدوجًا).
الخطوط مضمّنة محليًا في `assets/fonts` (رخصة OFL)، ولا توجد أي خدمة خارجية.

- للعرض أمام المشرفين: زر «عرض منطق التصميم» (في البوابة وفي نهاية الرحلة)، أو `Shift + D` من أي شاشة.
- روابط مباشرة للعرض: `index.html#evap` ، `#cloud` ، `#rain` ، `#mission` ، `#map` ، `#adapt`.

## ١. خريطة بنية المشروع

```
البوابة → التشخيص → مختبر الشمس → مختبر السحب → مختبر المطر → مهمة الإنقاذ → خريطة تعلمي → كيف تكيفت رحلتي؟
              │            ↑              ↑              ↑              ↑
              └────── المحرك التكيفي (نموذج المتعلم + قواعد قابلة للتعديل) ──────┘
```

## ٢. الشاشات

| # | الشاشة | الهدف الواحد |
|---|--------|-------------|
| ١ | بوابة المهمة | إثارة السؤال: «حدث خلل في دورة المياه!» |
| ٢ | التشخيص الأولي | تسجيل التوقّع دون تصحيحه؛ يحدد مستوى الدعم التالي |
| ٣ | مختبر الشمس | اكتشاف التبخر (الحرارة ↑ → حركة الجزيئات ↑ → البخار ↑) |
| ٤ | مختبر السحب | اكتشاف التكاثف (بخار → قطرات → سحابة عند برودة الهواء) |
| ٥ | مختبر المطر | اكتشاف الهطول (كمية البخار + حجم القطرات) |
| ٦ | مهمة الإنقاذ | تطبيق الدورة كاملة + شرح السلسلة + اكتشاف التجمع |
| — | خريطة تعلمي | حالة التعلم لكل مفهوم ومسار الرحلة، لا درجة رقمية |
| — | كيف تكيفت رحلتي؟ | كشف القرارات الحقيقية التي اتخذها النظام، ومقارنة برحلات متعلمين تجريبيين |

كل مختبر يتبع الدورة نفسها: **مهمة قصيرة → تفاعل → ملاحظة → سؤال استنتاجي → تغذية راجعة**.
السؤال لا يظهر قبل التجربة، والمصطلح العلمي لا يظهر إلا بعد الاكتشاف.

## ٣. منطق التكيف (حقيقي في الكود)

كل القواعد في كائن واحد: `js/core/adaptive.js → WC.RULES`، والمحرك `WC.Engine` ينفّذها.

| الموقف | القرار الذي تنفّذه الشاشة |
|--------|--------------------------|
| التشخيص: «يبقى كما هو» | مختبر الشمس يبدأ بأداة المقارنة وسؤال من نُقطة |
| التشخيص: «يتحول إلى مطر مباشرة» | دعم أولي في التبخر **والتكاثف** + تنبيه إلى المراحل الوسيطة |
| التشخيص صحيح | استكشاف حر دون تلميحات |
| أول خطأ في مفهوم | تجربة إضافية خاصة به، والسؤال مقفل حتى تكتمل: مقارنة قياسية (التبخر)، تبريد بطيء بجدول ملاحظات (التكاثف)، مقياس ثقل القطرة (الهطول)، مطر قوي لتتبّع المسار (التجمع) |
| الخطأ الثاني | سقالة من نُقطة + إخفاء الخيارات المستبعدة |
| الخطأ الثالث | عرض موجّه تضبط فيه نُقطة المؤشر بنفسها، ثم خياران فقط |
| إتقان من أول محاولة | لا إعادة للشرح + تحدٍّ أعلى (سؤال نقل، أو «اجعل المطر غزيرًا») |
| احتاج التبخر إلى دعم | تذكير قصير في مختبر السحب (ويُحذف لمن أتقن ويُقال له ذلك) |
| احتاج التكاثف إلى دعم | مقياس الثقل يظهر من بداية مختبر المطر |
| المهمة النهائية | المفاهيم التي فيها أخطاء تصبح هي الأعطال؛ من أتقن كل شيء يواجه ٣ أعطال دون أسماء للمراحل |
| تعثّر في المهمة | `Engine.missionBlock` يشخّص الحلقة المتوقفة من حالة المحاكاة، فيأتي التلميح عنها (سؤال ثم توجيه) |

كل قرار يُسجَّل بصيغة: **استجابة → تشخيص → احتياج → قرار → تغذية راجعة → نتيجة (إعادة التقييم)**،
وهذا السجل هو ما تعرضه شاشة «كيف تكيفت رحلتي؟» ولوحة المصمم.

حالة المفهوم في الخريطة: `● متقن` · `◐ أتقن بعد تجربة إضافية` · `◐ أتقن بعد دعم من نُقطة` · `○ يحتاج إلى تحدٍ إضافي`.

## ٤. مكونات المحاكاة (`js/sims`)

| الملف | المتغيرات | العلاقة المرئية |
|-------|-----------|-----------------|
| `evaporation.js` | حرارة الشمس | سرعة الجزيئات ومعدل البخار يزدادان مع الحرارة؛ أداة قياس للمقارنة |
| `condensation.js` | حرارة الهواء | البخار يتحول إلى قطرات في الطبقة الباردة وتتجمع سحابة؛ الدفء يعيدها بخارًا |
| `precipitation.js` | كمية البخار، حجم القطرات | الهطول عندما يكفي الماء وتثقل القطرات (`WC.RAIN_RULE`) |
| `cycle.js` | الأربعة معًا | سلسلة سببية بتأخّر مقصود ☀️ ← 💧 ← 💨 ← ☁️ ← 🌧️ ← 🏞️ ليُرى انتقال التغيير حلقةً بعد حلقة (`WC.CYCLE_MODEL`) |

المحاكاة تعليمية مبسطة، لا نموذج فيزيائي. وبجانب كل حركة مؤشر لفظي (بطيئة/متوسطة/سريعة)، فالفهم لا يعتمد على الحركة وحدها.

## الإتاحة (UDL)

اتجاه RTL، أرقام عربية شرقية في كل واجهة المتعلم، تشغيل الصوت أو إيقافه (قراءة رسائل نُقطة) وزر «استمع»، تكبير الخط، رموز مع نص دائمًا، حالات لا تعتمد على اللون وحده، أزرار كبيرة، لوحة مفاتيح كاملة (المؤشرات عناصر `range` أصلية)، واحترام إعداد تقليل الحركة.

## الاختبار

```
npm i playwright   # إن لم يكن مثبتًا
node tests/e2e.js struggle   # متعلم يحتاج إلى دعم: كل درجات السلّم التكيفي
node tests/e2e.js master     # متعلم متقن: التحديات والمهمة الأصعب
```

يغطي الاختبار: كل الأزرار والمسارات، حالات الخطأ وإعادة التجربة، RTL، غياب الأرقام اللاتينية من واجهة المتعلم، استجابة المحاكاة للتحكم، فعالية المسار التكيفي، لوحة المصمم، لوحة المفاتيح، وعرض الجوال.
